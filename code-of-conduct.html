Code of Conduct (OMARA)

Última actualización: 13 de mayo de 2026

Compromiso profesional

Los agentes migratorios registrados en Australia deben cumplir con el Code of Conduct establecido por la Office of the Migration Agents Registration Authority (OMARA). Este código define estándares de conducta profesional, comunicación, manejo de información, honorarios, registros, conflictos de interés y respuesta ante reclamos.

Código vigente

El Code of Conduct vigente entró en efecto el 1 de marzo de 2022 y está prescrito por las Migration (Migration Agents Code of Conduct) Regulations 2021. OMARA indica que el código establece las reglas que un agente migratorio registrado debe cumplir para permanecer en el registro.

Qué podés esperar

  • Información clara sobre el servicio, alcance del trabajo, honorarios y costos.
  • Comunicación profesional, honesta y oportuna durante el proceso.
  • Manejo confidencial y responsable de documentos e información personal.
  • Evaluación realista del caso, sin promesas de resultado ni garantías indebidas.
  • Registros adecuados del trabajo realizado y de las comunicaciones relevantes.
  • Procedimientos claros si surge una consulta, desacuerdo o reclamo.
