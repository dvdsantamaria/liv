Code of Conduct (OMARA)

Last updated: 13 May 2026

Professional commitment

Registered migration agents in Australia must comply with the Code of Conduct set by the Office of the Migration Agents Registration Authority (OMARA). The code defines standards for professional conduct, communication, information handling, fees, records, conflicts of interest and responses to complaints.

Current code

The current Code of Conduct came into effect on 1 March 2022 and is prescribed by the Migration (Migration Agents Code of Conduct) Regulations 2021. OMARA states that the code sets the rules a registered migration agent must follow to remain registered.

What you can expect

  • Clear information about the service, scope of work, professional fees and costs.
  • Professional, honest and timely communication throughout the process.
  • Confidential and responsible handling of documents and personal information.
  • A realistic case assessment, without false promises or improper guarantees.
  • Appropriate records of work completed and relevant communications.
  • Clear steps if a question, disagreement or complaint arises.
